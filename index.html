PROBLEM

문제

독거노인 및 시각장애인 등 소외계층은 반려동물의 이상행동을 육안으로 포착하거나 그 심각도를 판단할 수단이 부족할 수 있습니다. 따라서 정작 위급한 순간에 병원 방문이나 응급처치와 같은 빠른 대처가 이어지지 못할 수 있습니다.

SOLUTION

해결 — 만들고, 실제로 눌러보며 검증했습니다

AI에게 구현을 맡기는 것에서 끝내지 않고, 실제 브라우저에서 직접 기능을 눌러보며 문제를 발견하고 고친 팀 활동 디버깅 기록입니다.

팀 활동 디버깅 기록 — 코드만 보고 믿지 않고, 로컬 서버와 다른 기기에서 직접 실행해 아래 4가지 문제를 발견하고 해결했습니다.

01

로그인/회원가입 시 '서버 연결 안됨' 에러

에러

signal_login.html, signal_signup.html에서 로그인·회원가입을 시도하면 서버 연결 안 됨 오류가 떴습니다.

원인

코드 버그가 아니라 사용법 문제였습니다. HTML 파일을 더블클릭해 file:// 프로토콜로 열면, 페이지 안의 상대경로 fetch('/api/...') 호출이 실제 서버로 가지 않아 요청 자체가 실패했습니다.

해결

python app_server.py로 백엔드 서버를 켜고 반드시 http://localhost:8850/... 주소로 접속하도록 안내했고, 프로토콜이 file://일 때 원인을 바로 알려주는 에러 메시지를 로그인·회원가입 페이지에 추가했습니다.

02

오프라인 모드 fetch 우회의 윈도우 드라이브 문자 버그

에러

file://로 열었을 때를 대비한 오프라인 fetch 우회 로직이 크롬·엣지 브라우저에서 조용히 실패하고, 실제 네트워크로 새어나가 CORS에 막혔습니다.

원인

크롬 계열 브라우저가 file:///C:/... 기준으로 절대경로 /api/login을 다시 계산할 때 드라이브 문자를 그대로 붙여 /C:/api/login으로 만들어, /api/로 시작하는지 확인하는 경로 체크가 매칭되지 않았습니다.

해결

정규식 path.replace(/^\/[A-Za-z]:(?=\/)/, '')로 드라이브 문자 접두사를 제거하는 코드를 추가했습니다. 처음엔 8개 파일에 적용했는데, 최종 검토 중 signal_guide.html에만 패치가 누락된 것을 추가로 발견해 마저 반영했습니다.

03

인덱스 페이지 통계 카드 색상이 전부 똑같아 안 보이는 에러

에러

홈 화면 'WHY SIGNAL' 통계 카드 4개의 강조 색상이 눈에 안 띈다는 피드백이 있었습니다.

원인

색상 값 자체의 대비 문제가 아니라, --accent-sky, --accent-mint, --accent-coral, --accent-violet 네 개의 CSS 변수가 팔레트 리스킨 작업 중 복사·붙여넣기 실수로 전부 동일한 색으로 설정돼 있었습니다.

해결

같은 팔레트 안의 서로 다른 진한 색(--danger, --brand-green-deep, --ok, --signal-yellow)을 각 변수에 재할당해 네 카드가 구분되도록 고쳤습니다.

04

신규 추가 견종에서 "등록된 강아지 없음"으로 잘못 표시되는 회귀

에러

마이페이지 확장으로 지원 견종을 14종에서 약 42종으로 늘렸는데, 건강정보 화면에서 새로 추가된 약 28개 견종을 선택하면 실제로는 강아지가 등록돼 있어도 "등록된 강아지 없음"이라고 잘못 표시됐습니다.

원인

getBreedHealth() 함수가 기존 14종의 견종 이름만 알고 있어서, 새로 추가된 견종 ID를 찾지 못하고 미등록 상태로 오판했습니다.

해결

OTHER_BREED_NAMES 매핑 테이블과 GENERIC_HEALTH 기본값을 추가해, 목록에 없는 견종이라도 최소한 이름과 일반적인 건강 팁은 보여주도록 수정했습니다.

MY ROLE · AI

나의 역할 · AI 활용

제품 방향(브랜드 톤, 기능 범위, 안전 문구 원칙)을 담은 상세 기획서와 참고 논문을 준비해 AI에게 구현을 맡겼습니다. AI가 만든 결과물은 코드만 보고 믿지 않고, 실제 브라우저(로컬 서버·다른 기기)에서 직접 눌러보며 검증했습니다. 이 과정에서 지도 검색 실패, API 키/도메인 불일치, 보안 프로그램 차단 등 실제 문제를 여러 번 발견하고 스크린샷으로 공유해 함께 원인을 좁혀갔습니다. 최종적으로 발표할 PPT를 만들어 주요 내용이 잘 담길 수 있도록 제작했습니다.

건강관리

지금 되는 기능

체중 추이 차트 + 규칙 기반 식단/운동 조언 + 급감 경고 → AI 진단 연결

앞으로 어떻게 고칠 것인가

지금은 '내 반려동물' 프로필에 체중을 한 번만 입력하는데, 날짜별 기록으로 바꿔서 SVG 라인차트로 보여주고, 직전 대비 5% 이상 빠지면 'AI 건강진단에서 확인하기'로 유도하는 구조로 고칩니다. 계산 로직이 단순(if/else 템플릿 조합)해 구현 부담이 적고, AI진단·펫프로필과 자연스럽게 이어집니다.

2

주변시설 · 산책

지금 되는 기능

'우리 동네' 등록 + 계층 정렬(우리 동 → 같은 구 → 그 외)

앞으로 어떻게 고칠 것인가

GPS 실패·실내·위치거부 시에도 결과를 보여줄 수 있는 폴백입니다. 다만 대전 82개 행정동을 통째로 하드코딩하는 건 지역 확장성이 떨어지므로, '내 동네'를 텍스트/드롭다운으로 직접 입력받아 Kakao 좌표 변환(주소→좌표) API로 처리하는 방식으로 고칩니다. 그러면 대전에 한정되지 않고 전국 어디서나 동작합니다.

반려 가이드 · 커뮤니티

앞으로 어떻게 고칠 것인가

둘 다 게시판·유저 작성 없이 정적 데이터라 구현 난이도는 낮습니다. 다만 가이드의 유전병 설명은 출처 표기 없이 통설 수준이라, 넣기 전에 AKC·수의학 자료로 재검증이 필요합니다. 커뮤니티 외부 링크(하이뉴스·로얄캐닌 등)도 실제 살아있는지 확인이 필요해, verify-sources로 검증할 수 있도록 고칩니다.
